# RAWLAB_

Creative digital platform by Raúl Ruiz.

RAWLAB_ is a living digital archive where movement, code, design, photography and human experience coexist.

## Concept

RAWLAB_ is not a static portfolio.  
It is a personal creative system built as both a web platform and a future mobile app.

The project explores:

- creative coding
- frontend engineering
- mobile experiences
- design systems
- visual archives
- climbing and movement
- personal writing
- cloud architecture
- connected digital identity

## Current Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Current Features

- Responsive landing page
- Interactive hero collage
- Adaptive atmosphere system
- VOID / LIGHT environment toggle
- Animated starfield background
- Cursor reactive glow
- Bilingual copy system ES / EN
- Visual archive carousel
- Image modal preview
- Scroll progress indicator
- Active navigation by section
- Mobile navigation
- Connected signals section
- Documents access layer

## Future Integrations
